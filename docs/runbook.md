# Public Showcase Maintenance Runbook

## Routine review

At least periodically, verify:

1. README links work;
2. CI passes;
3. no confidential source or binary backup has been added;
4. architecture/result claims still match the approved private evidence;
5. client identity and account/provider identifiers remain absent;
6. website metadata remains aligned with the same public evidence record.

## Withdrawal

If a disclosure, ownership or contractual concern arises:

1. stop further promotion immediately;
2. preserve the concern privately;
3. set portfolio status to withdrawn/blocked;
4. remove or privatize the public artifact only through founder-approved action;
5. update website/public channels consistently.

Do not silently rewrite history to hide a security incident without an approved response plan.
