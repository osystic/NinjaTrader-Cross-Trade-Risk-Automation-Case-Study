# Governance Exceptions

## GitHub account model

The canonical `osystic` GitHub owner is reported by GitHub as a user account rather than an organization in the current environment. Organization-only team/base-permission enforcement described by OSYSTIC Governance v2.2 is therefore not technically applicable here.

The repository still follows the same publication gate, sanitized-history, documentation, CI and confidentiality controls.

## Closeout-created public proof

The case-study repository was deliberately authored after project acceptance. It does not fabricate development history, client commits or private pull requests. Its Git history begins with the sanitized public artifact.
