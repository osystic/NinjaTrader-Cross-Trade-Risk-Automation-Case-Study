# Contributing

This public showcase is maintained under OSYSTIC GitHub Governance v2.2.

- Work through an issue and a short-lived branch.
- Use pull requests into `main`.
- Keep every claim evidence-backed and confidentiality-safe.
- Do not add confidential source, private screenshots/logs, account information, credentials, commercial terms or private conversations.
- Do not turn the case study into a trading-strategy or signal repository.
- Any new public claim must remain within the approved disclosure boundary.

Security or privacy concerns block publication until resolved.
